# TurfBook Kerala

Online turf booking for Kerala: Django REST API + React (Vite) frontend, with OpenStreetMap maps (Leaflet, no API key needed).

## Run it

Backend (Python 3.11+):

```bash
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python manage.py makemigrations accounts turfs bookings
python manage.py migrate
python manage.py seed_turfs          # sample Kerala turfs, demo users
python manage.py createsuperuser     # optional, for /admin/
python manage.py runserver           # http://127.0.0.1:8000
```

Frontend (Node 18+):

```bash
cd frontend
npm install
npm run dev                          # http://localhost:5173 (proxies /api to Django)
```

For production, set `VITE_API_URL` for the frontend and `DJANGO_SECRET_KEY`, `DJANGO_DEBUG=0`,
`DJANGO_ALLOWED_HOSTS`, `CORS_ALLOWED_ORIGINS` for the backend.

## Pages

Home, Browse turfs (list and map views with filters), Turf detail (gallery, map, slot booking, reviews),
Checkout, Booking ticket, My bookings, Favourites, Login, Register, Profile, Owner dashboard,
Add/Edit turf (with map location picker), About, Contact, FAQ, Terms, Privacy, 404.

## Images

Artwork is in `frontend/public/img/` (SVG illustrations generated by `tools/gen_images.py`).
Replace them with real photos by changing the `images` list on each turf.
